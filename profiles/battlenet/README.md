# Battle.net / Blizzard profiles

YAML profiles for Blizzard games imported via `import_game.command add-battlenet`.

Naming: `battlenet-<slug>.yaml` with `store: battlenet` and `exe_path` set to the
game executable relative to the bottle's `drive_c`.

See [docs/PROFILE_FORMAT.md](../../docs/PROFILE_FORMAT.md) and
[docs/STORE_IMPORT.md](../../docs/STORE_IMPORT.md).

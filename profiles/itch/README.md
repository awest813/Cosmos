# itch.io profiles

YAML profiles for Windows games imported via `import_game.command add-itch`.

Naming: `itch-<slug>.yaml` with `store: itch` and `exe_path` set to the game
executable relative to the bottle's `drive_c` (under `drive_c/Games/<slug>/`).

See [docs/PROFILE_FORMAT.md](../../docs/PROFILE_FORMAT.md) and
[docs/STORE_IMPORT.md](../../docs/STORE_IMPORT.md).

# Standalone profiles

YAML profiles for non-Steam games imported via `import_game.command`.

Naming: `standalone-<slug>.yaml` with `store: standalone` and `exe_path` set to the
game executable relative to the bottle's `drive_c`.

See [docs/PROFILE_FORMAT.md](../docs/PROFILE_FORMAT.md) and
[docs/STORE_IMPORT.md](../docs/STORE_IMPORT.md).
